# Estanis Apps

Central dos aplicativos desenvolvidos por Estanis.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000

## Rotas

- `/`
- `/apps/combustivel`
- `/apps/combustivel/privacidade`
- `/apps/combustivel/termos`

## Deploy

Este projeto pode ser conectado diretamente a um repositório GitHub e importado na Vercel.

## Próximos passos

1. Criar repositório GitHub.
2. Subir o projeto.
3. Importar o repositório na Vercel.
4. Definir domínio quando quiser.
5. Antes da publicação final, revisar a Política de Privacidade e o formulário Data Safety do Google Play para refletirem exatamente as versões e SDKs usados no aplicativo.
